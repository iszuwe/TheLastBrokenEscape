# The Last Broken Escape

A Unity horror game set in a flooded, abandoned world. Explore the environment, survive the creature, and find a way out.

## Requirements

- Unity `2021.3.45f1`
- Windows 10/11 for the included build

## Play the Windows build

Download the latest Windows build from the repository's **Releases** page, extract the ZIP, and run:

`A195348 The Last Broken Escape.exe`

Keep the `_Data` folder, `UnityPlayer.dll`, and the other files beside the executable.

## Open the project

1. Clone this repository.
2. Open it with Unity `2021.3.45f1`.
3. Open a scene from `Assets/Scenes` or the scene included with the project.
4. Press **Play** in the Unity Editor.

## Build

Use **File → Build Settings**, select **Windows, Mac, Linux**, choose **Windows**, and click **Build**. Distribute the complete build folder as a ZIP.
